# WheelCart MindAR setup

## First AR prototype

The existing Three.js wheel viewer is retained. The feature branch adds MindAR image tracking and attaches the existing wheel group to image target 0.

### Create the compiled target

1. Open the [MindAR Image Target Compiler](https://hiukim.github.io/mind-ar-js-doc/tools/compile/).
2. Upload `public/targets/wheelcart-marker.svg` (if SVG upload is rejected, export it as PNG).
3. Start compilation and inspect the feature-point visualization. The target needs a good, well-distributed feature score; the logo artwork may need revision if the score is poor.
4. Download the compiled `.mind` file.
5. Add it to this repository as `public/targets/wheelcart.mind`.

The application expects this exact path: `/targets/wheelcart.mind`.

### Build

```bash
npm install
npm run build
```

Deploy the contents of `dist/` to the `wheelcraft.expert-end.com` document root. Camera access requires HTTPS.

### Important
The `.mind` file is generated by the compiler and is not included yet. Do not publish the AR prototype as ready until the target is compiled, the dependency lockfile is refreshed, and the production build plus real-device camera test pass.
